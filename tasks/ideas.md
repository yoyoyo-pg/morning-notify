## さかなクン 改善計画

### AI 要約の導入

**現状**: RSS の `summary` フィールドを HTML 除去・80字切り詰めで表示。記事本文の抜粋であり、質はフィード依存。

**やりたいこと**: Claude API（または他の LLM）で各記事の本文をスクレイピングしてから 1〜2 文に要約する。

**実装イメージ**
```
- 記事URLからBeautifulSoupで本文取得
- Claude API に「50字以内でさかなクン口調で要約して」と投げる
- Anthropicの無料枠 or 安価なモデル（claude-haiku）を使う
```

**懸念点**
- Anthropic API キーの追加（GitHub Secrets）が必要
- 記事によってはスクレイピングが弾かれる（robots.txt）
- 実行時間が増加する（GitHub Actions の課金に影響する可能性）
